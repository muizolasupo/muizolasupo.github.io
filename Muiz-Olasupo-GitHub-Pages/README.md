# Muiz Olasupo portfolio

## Publish
1. Create the public repository muizolasupo.github.io on the muizolasupo account.
2. Extract this ZIP and upload its contents to the repository root. index.html must be at the top level, alongside images/ and icons/.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open https://muizolasupo.github.io after deployment succeeds.

## Updates
Edit or replace the relevant files and commit to main. GitHub Pages republishes them.
The CV uses the existing Google Drive file. Update that file through Manage versions to preserve its URL.
Changes made in the original ChatGPT-hosted portfolio do not automatically sync to this GitHub repository.

## Custom domain
After purchasing your domain, configure it in Settings > Pages > Custom domain and follow GitHub's current DNS instructions:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
